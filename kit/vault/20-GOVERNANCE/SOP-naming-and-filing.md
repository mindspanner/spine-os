# SOP — Naming and filing

- **When:** every time you save something.
- **Owner:** you (your AI follows it too).

## File names
`YYYY-MM-DD topic type.ext` — the date first so files sort in time order.
- `2026-11-02 referral letter.pdf`
- `2026-11-02 note.md` (inside a client's `notes/` folder)
- `2026-11-02 insurance renewal certificate.pdf`

Rules: no client names (use the code, e.g. `C-0007`); no `final`, `final2`, `new` — the date says which
is newest; keep names short; letters, numbers, spaces and dashes only.

## Folders — one home for each thing
| It is about… | It lives in… |
|---|---|
| Not sorted yet | `00-INBOX/` |
| A piece of work with an end | `10-PROJECTS/<project>/` |
| How you work and what you decided | `20-GOVERNANCE/` |
| One client or person | `30-CLIENTS/<code>/` |
| Everything else you keep (forms, templates, admin) | `40-DOCUMENTS/` (if installed) |
| Routines you repeat | `systems/` |
| Anything with a date | `REMINDERS.md` (if installed) |

## One copy only
Move, don't copy. If two versions exist, keep the newest, and move the old one to
`<folder>/_old/` until your next weekly review.

## Finding things later
Ask your AI "find …". It looks at names first — which is why good names matter.
