# Security baseline — the 10 things to have on

Do these once. Tick them off. Your AI can walk you through each one ("help me with item 3").

| # | Do this | Mac | Windows |
|---|---|---|---|
| 1 | Encrypt the computer's disk | System Settings → Privacy & Security → FileVault → Turn On | Settings → Privacy & security → Device encryption (or BitLocker) → On |
| 2 | Lock the screen after 5 minutes | System Settings → Lock Screen | Settings → Accounts → Sign-in options → "If you've been away" |
| 3 | Keep the system updated | System Settings → General → Software Update → Automatic | Settings → Windows Update → On |
| 4 | Use a password manager | Apple Passwords, 1Password or Bitwarden | Same |
| 5 | Turn on two-step sign-in (MFA) for email, cloud storage and your AI account | In each account's security settings | Same |
| 6 | Back up this folder (3 copies, 2 kinds of storage, 1 off-site) | `SOP-data-backup-3-2-1.md` | Same |
| 7 | Client names never in file names — use codes | `SOP-naming-and-filing.md` | Same |
| 8 | Keep keys and passwords out of this folder | Use the password manager or the system keychain | Same |
| 9 | Check what your AI may send online | `.spineosignore` + `SOP-llm-assistant-use.md` | Same |
| 10 | Know what to do if a laptop is lost or a file goes to the wrong person | `SOP-incident-record.md` | Same |

## Cloud sync folders (iCloud, OneDrive, Google Drive, Dropbox)
Fine for backup, risky as the only home: two devices editing at once makes "conflicted copy" files.
If you sync this folder, edit on one device at a time, and record the choice as a decision.

## Health, case or legal records
Check your profession's and employer's rules before storing identifiable records here. If your service
has an official records system, that system is the record; this folder holds your own working files only
where your policy allows. Not legal advice.
