# SOP — Weekly review (the 30 minutes that keeps the system honest)

- **When to run this:** once a week, same slot every week. Friday afternoon or Monday morning both work — pick one and defend it.
- **Owner:** you
- **Last reviewed:** YYYY-MM-DD

## Purpose

A small business drifts when nobody looks at the whole board. The weekly review is the single recurring habit that empties your inbox, refreshes every project status, and tells you the two or three things that actually matter next week — so the dashboard you open on Monday is telling the truth.

## Inputs

- `00-INBOX/` — everything captured but not yet sorted.
- `10-PROJECTS/` — every active project file.
- `30-CLIENTS/` — open matters and their next actions.
- Your calendar and, optionally, your bank balance / accounting tool.

## Outputs

- An empty (or near-empty) `00-INBOX/`.
- Every active project with an accurate `Status` and exactly one `Next action`.
- A short list of next week's priorities (kept wherever you'll see it).

## Steps

1. **Clear the inbox.** Open `00-INBOX/`. For each item, do one of: file it (to a project or client), turn it into a project, or make a deliberate "no" and delete it. Two minutes per item maximum — if it needs more, file it as a project and move on.
2. **Sweep projects.** Open each file in `10-PROJECTS/`. Confirm the `Status` (active / paused / done). If `done`, set it and stop touching it. For everything active, make sure the `Next action` is a single physical step you could do tomorrow.
3. **Sweep clients.** Open `30-CLIENTS/`. For each active matter, confirm its next action is real. Mark dormant relationships `dormant` so they stop nagging you visually.
4. **Look at money (briefly).** Glance at outstanding invoices and your next few weeks of income. You're not doing the books here — you're catching the one invoice that slipped.
5. **Pick the week.** Write down the two or three things that, if done, make next week a win. Be honest: a list of fifteen is a list of zero.
6. **Note anything that recurred.** If you've now done the same fiddly thing three weeks running, that's a candidate for a new SOP. Jot it; don't write it now.

## Done when

The inbox is empty, every active item names one next action, and you can say in one sentence what next week is about.

## Worked example

A freelance designer's Friday review:

1. Inbox had 4 items: a referral (→ new project), a receipt (→ filed to client), a "we should catch up" email (→ deliberate no, replied and deleted), a font idea (→ filed to a someday note).
2. Projects: "Bakery rebrand" still active, next action corrected from "keep going" to "send logo round 2"; "Old portfolio site" marked `done`.
3. Clients: "Bakery" active; "Last year's gym client" set to `dormant`.
4. Money: one invoice 40 days overdue — noted as next week's priority #1.
5. Week's three: chase overdue invoice, send logo round 2, write the proposal for the referral.

> This is an admin habit, not advice. Adapt the cadence and checks to your own business.
