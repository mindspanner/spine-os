# Your Spine OS vault

This is your business on your hard drive: a set of plain-markdown folders you fully own. Open them in any
editor, sync them with any tool you trust, back them up however you like. Nothing here phones home.

## The lanes (in the order work flows)

| Lane | What lives here |
|------|-----------------|
| [`00-INBOX/`](00-INBOX/) | Anything captured but not yet sorted. Empty it in your weekly review. |
| [`10-PROJECTS/`](10-PROJECTS/) | One folder/file per engagement or initiative. Copy `_TEMPLATE.md` to start. |
| [`20-GOVERNANCE/`](20-GOVERNANCE/) | The rules the system runs by: SOPs (procedures), ADRs (decisions), and your privacy note. |
| [`30-CLIENTS/`](30-CLIENTS/) | People and matters. Copy `_TEMPLATE.md` per client. Keep it on your turf. |
| [`systems/`](systems/) | Runnable playbooks (Morning Briefing, Weekly Review, Client Intake) you follow yourself or hand to an assistant. |
| `40-DOCUMENTS/` *(optional extra)* | Templates, forms, reference and admin papers that are not about one client or project. |
| `REMINDERS.md` *(optional extra)* | One list for everything with a date. |

Optional extras are offered when you install (documents · client/case files · reminders · email help ·
AI shortcuts). Run the installer again on this folder to add one later.

## What's already in here (so you're not starting from a blank page)

This vault ships with **real, usable content** — not just empty templates:

- **`20-GOVERNANCE/`** — eight worked SOPs (client intake, weekly review, monthly finance close, 3-2-1
  backups, document generation, incident record, record retention, AI-assistant use), three example ADRs
  with an ADR template, a decisions log, and a plain-English **Australian Privacy starter note**.
- **`systems/`** — three runnable playbooks with checklists and filled examples.
- **Example data** — sample projects, a sample client, and an inbox note (all clearly marked
  `EXAMPLE-…`) so the dashboard shows something real on day one. Delete them, or keep them as models.

## Start here (15 minutes, day one)

1. Open the [Morning Briefing](systems/Morning-Briefing.md) — it's the daily habit that makes the rest pay off.
2. Read [`20-GOVERNANCE/`](20-GOVERNANCE/) — skim the SOPs; they're short on purpose.
3. Copy a template: `30-CLIENTS/_TEMPLATE.md` for your first real client, or `10-PROJECTS/_TEMPLATE.md` for your first project.
4. Set up backups today — [`SOP-data-backup-3-2-1`](20-GOVERNANCE/SOP-data-backup-3-2-1.md). Future-you will thank you.
5. Delete the `EXAMPLE-…` files once you've seen how they work.

## How to remove the example data

The starter samples are the files whose names begin with `EXAMPLE-`. Delete them whenever you like — they
exist only to show the shape of a healthy file and to give the dashboard something to display.

## The one rule that makes all this work

Information lives in **one place**. Capture fast (inbox), sort weekly (weekly review), decide once (write
an ADR), and run repeatable work from an SOP. Everything is plain text, so you can read it in any editor,
move it to any tool, and never get locked out.

> This vault is illustrative business-admin scaffolding. It is **not** a clinical records system and
> **not** legal, financial or professional advice. Adapt it to the privacy and professional obligations
> that apply to you before relying on it for real work.
