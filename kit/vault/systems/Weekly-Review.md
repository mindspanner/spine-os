# System — Weekly Review

> A runnable playbook that operationalises `20-GOVERNANCE/SOP-weekly-review.md`. The SOP says *what* the
> weekly review is; this system is the *do-it-now* version you can follow line by line, or hand to your
> assistant to prepare.

**What it does:** the one recurring habit that keeps the whole system honest — empties the inbox,
refreshes every project status, and leaves you with two or three priorities for next week.

**When to run:** once a week, same slot every week.

**Time:** ~30 minutes.

---

## Run it yourself (manual)

1. **Clear `00-INBOX/`.** For each item: file it, make it a project, or make a deliberate "no". Nothing stays.
2. **Sweep `10-PROJECTS/`.** Update each `Status`; ensure every active project has exactly one real `Next action`; mark finished ones `done`.
3. **Sweep `30-CLIENTS/`.** Confirm each active matter's next action; mark quiet relationships `dormant`.
4. **Glance at money.** Outstanding invoices, next few weeks' income. Catch the one that slipped.
5. **Choose the week.** Write the 2–3 things that make next week a win. Be ruthless.
6. **Note recurring work.** Anything you've now done three times → flag as a future SOP (don't write it now).

## Run it with your assistant (BYO-LLM)

> "Read `00-INBOX/`, `10-PROJECTS/` and `30-CLIENTS/`. For each project and client, list its current
> status and next action, and flag any with a stale or missing next action, anything marked active with
> no recent activity, and any invoice that looks overdue. Then propose 2–3 priorities for next week.
> Use only what's in the files; don't invent anything."

Use the assistant's output as a *worksheet*. You make the calls and do the filing.

## Checklist

- [ ] `00-INBOX/` empty
- [ ] Every project: status accurate, one next action, finished ones marked `done`
- [ ] Every client: matters current, dormant ones marked
- [ ] Money glanced at; slipped invoice caught
- [ ] 2–3 priorities chosen for next week
- [ ] Recurring work flagged for a future SOP

> Skipping the weekly review is how a tidy system quietly rots. Defend the slot.
