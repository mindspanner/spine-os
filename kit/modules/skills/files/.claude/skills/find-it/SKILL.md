# Find it

1. Search file and folder names first, then file contents, inside this vault only.
2. Prefer `MEMORY.md` and folder `README.md` files as a map.
3. Answer with: the best match (path), one line on why, and up to 3 other likely matches.
4. Read the file only if the person wants the answer from inside it.
5. If nothing matches, say so and suggest where it *should* live per `SOP-naming-and-filing.md`.
Never send file contents from `vault/30-CLIENTS/` or anything listed in `.spineosignore` to an
online service.
