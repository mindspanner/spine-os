# Case note

1. Ask for the client code if not given (e.g. C-0007). Never use or ask for the full name.
2. Take the person's rough notes or dictation. Do not invent facts, quotes, risk findings or diagnoses.
3. Write it in `_NOTE-TEMPLATE.md` layout: Data · Assessment · Plan, plus time and mode.
4. Mark anything you inferred with "(check)". Leave risk wording exactly as the person gave it.
5. Show the draft. On a yes, save to `vault/30-CLIENTS/<code>/notes/YYYY-MM-DD note.md`
   (add `-2` if one exists) and add any dated next step to `vault/REMINDERS.md` if it exists.
6. The practitioner owns the note. Remind them to read it before relying on it.
