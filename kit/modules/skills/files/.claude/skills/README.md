# AI shortcuts (skills)

Ready-made instructions your AI follows when you ask in plain words.

| Say | Skill |
|---|---|
| "sort my inbox" | `sort-inbox` |
| "find the …" | `find-it` |
| "write a note for C-0007" | `case-note` |
| "what's due?" / "remind me to …" | `whats-due` |
| "draft a reply to …" | `draft-email` |
| "weekly review" | `weekly-review` |
| "check this for private details" | `privacy-check` |
| "check for updates" | `keep-current` |

- **Claude Code:** works automatically when you run Claude in this folder.
- **Claude Desktop / Cowork:** works when this folder is connected; or zip a skill folder and add it in
  Settings → Capabilities → Skills.
- **ChatGPT and others:** say "read .claude/skills/<name>/SKILL.md and do it".
