# Documents

One home for documents that are not about one client or one project.

| Folder | Put here |
|---|---|
| `templates/` | Blank letters, forms and report shells you reuse. |
| `forms/` | Forms you fill in often (referrals, consent, intake). Keep the blank here; the filled copy goes in the client or project folder. |
| `reference/` | Guidelines, policies, articles you look things up in. |
| `admin/` | Registration, insurance, CPD certificates, contracts, finance paperwork. |

**The rule:** a document about one client lives in that client's folder. A document about one project lives in that project. Everything else lives here.

**File names:** `YYYY-MM-DD topic type.ext` — for example `2026-11-02 insurance renewal certificate.pdf`.
Never put a client's full name in a file name; use their client code. See `20-GOVERNANCE/SOP-naming-and-filing.md`.

**Finding things:** ask your AI "find the …" — it searches names first, then contents.
