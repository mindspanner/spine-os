# Routine — Reminders

**Trigger:** "what's due?", the morning briefing, or the weekly review.

1. Read `REMINDERS.md`.
2. List: overdue · due today · due in the next 7 days. One line each.
3. For repeating items marked done, add the next one (e.g. yearly → same date next year).
4. On request, write a calendar file: `00-INBOX/YYYY-MM-DD reminder <what>.ics`
   (standard iCalendar: VCALENDAR / VEVENT with DTSTART, SUMMARY, a 1-day VALARM). No client names
   in the SUMMARY — use the code.
5. Never send reminders to clients by yourself. Draft the message; the person sends it.
