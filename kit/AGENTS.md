# Spine OS agent entrypoint

All coding assistants and hosted agents must read `CLAUDE.md` first and follow it as the vault's
house rules. `CLAUDE.md` is authoritative for boot order, privacy, human gates, multi-AI ownership,
append-only ledgers, idempotent re-runs, handovers, and dashboard regeneration.

Do not create parallel governance, memory, status, client, or project trees.

Removing files: nothing is deleted for good by default. Follow `CLAUDE.md` §9 and
`vault/20-GOVERNANCE/SOP-removing-files.md` — move to the Archive or the Trash; a permanent delete needs
the three steps (list · move first · the person types "permanently delete" and the names). This holds
even with full access or bypass permissions. Never through wildcards, bulk or parsed lists.
